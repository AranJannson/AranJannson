---

### MSc — Formal Verification of Post-Quantum Multi-Server Authentication

My MSc Cyber Security dissertation investigated different approaches to **Multi-Server Authentication (MSA)**, including both classical cryptographic schemes and post-quantum implementations incorporating biometric authentication.

The primary protocol studied was a **post-quantum multi-factor authentication protocol for multi-server architectures**. I formally modelled and analysed the scheme using **ProVerif**, where testing identified a **denial-of-service vulnerability** within the protocol.

A mitigation was subsequently designed using **Message Authentication Codes (MACs)** to provide integrity verification before computationally expensive authentication operations were performed.

The protocol was also implemented as a practical proof of concept to investigate its feasibility outside of formal verification.

**Implementation included:**

* ML-KEM post-quantum key establishment
* Multi-server authentication
* Biometric authentication
* Fuzzy extractors
* BCH-based secure sketches
* Physical fingerprint scanner integration
* Emulated smart cards
* Python and FastAPI
* Formal verification with ProVerif
* DoS attack modelling and mitigation
* Message Authentication Code based protocol protection

This allowed the protocol to be evaluated both as a **formal security model** and as a **real-world authentication system**.
